## Identidade Visual & Tom de Voz

### Personalidade da Marca
O Bud Finance fala como um **amigo inteligente sobre finanças** — não um contador sério, nem um app frio. É acessível, direto e ocasionalmente bem-humorado.

### Tom
- ✅ "Você gastou R$480 em delivery esse mês. O Buddy notou 👀"
- ✅ "Sem planilha. Sem dor de cabeça."
- ✅ "Importe sua fatura em 30 segundos. A IA faz o resto."
- ❌ Evitar linguagem técnica desnecessária
- ❌ Evitar promessas de enriquecimento ("fique rico rápido")

### Paleta de Cores (para artes)
- Verde esmeralda `#10b981` — Receita, sucesso, saúde financeira
- Vermelho `#ef4444` — Despesa, alerta, limite estourado
- Azul `#2563eb` — IA, informação, botões principais
- Âmbar `#f59e0b` — Atenção, prazo, limite perto
- Fundo escuro `#0f172a` — Modo Dark HBO (tema premium)

## 1. Dashboard

### O que é
A tela inicial do app. Mostra uma visão completa das finanças do mês atual: saldo, entradas, saídas, gastos por categoria e as últimas transações.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Resultado do Mês** | Card principal com saldo = entradas − saídas. Verde se positivo, vermelho se negativo. |
| **Entradas do Mês** | Total de receitas registradas no mês atual. |
| **Saídas do Mês** | Total de despesas registradas no mês atual. |
| **Gráfico de Rosca** | Donut chart com as categorias que mais pesaram no mês. Hover revela o valor. |
| **Atividades Recentes** | Últimas 5 transações com emoji da categoria, data e valor. |
| **Histórico Completo** | Modal que lista todas as transações do mês com filtro Todos/Receitas/Despesas. |
| **Navegação por Mês** | Setas ← → para ver qualquer mês anterior. |
| **Ocultar Valores** | Toggle que substitui todos os números por "••••" — ideal para prints de tela. |
| **Nova Receita / Nova Despesa** | Botões de ação rápida para lançar uma transação sem sair do dashboard. |
| **Modo Edição Inline** | Clica em qualquer transação da lista para editar direto, sem abrir outra tela. |

### Problema que resolve
> "Quero saber numa olhada só se estou no positivo ou negativo esse mês — sem ter que somar tudo manualmente."

## 2. Extrato

### O que é
A lista completa de todas as transações — entradas e saídas — com filtros avançados, busca e exportação.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Transações agrupadas por dia** | As transações aparecem divididas por data, com total do dia. |
| **Filtros** | Por tipo (Todos/Receitas/Despesas), por categoria, busca por texto. |
| **Navegação por mês** | Setas para ver extratos de meses anteriores. |
| **Filtro por intervalo de datas** | Seleciona "De / Até" para ver qualquer período (ex: semana, bimestre). |

| **Marcar como pago/pendente** | Toggle para controlar o que já saiu da conta de verdade. |

| **Exportar CSV** | Baixa todas as transações do mês em planilha compatível com Excel. |
| **Exportar PDF** | Gera um extrato formatado com cabeçalho e totais, pronto para imprimir ou enviar. |

## 3. Metas

### O que é
Sistema de metas de economia. O usuário define um objetivo (viagem, carro, reserva de emergência), coloca um prazo e vai depositando. O app acompanha o progresso com visual gamificado.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Criar meta com emoji** | Picker de 120 emojis + 10 sugestões prontas (Viagem, Carro, Casa, Casamento, etc.). |
| **Prazo inteligente** | Define uma data-limite; o app sugere quanto depositar por mês para atingir o objetivo. |
| **Barra de progresso animada** | Progresso visual com gradiente azul→verde. Ao chegar em 100%: confete 🎉. |
| **Badges de gamificação** | 🌱 início → 🔥 metade → ⭐ quase lá → 🚀 90% → 🏆 concluída. |
| **Histórico de aportes** | Log de cada depósito com data, valor e saldo acumulado. |
| **Integração com Carteira** | Depositar numa meta pode debitar automaticamente de uma conta cadastrada. |
| **Sugestão de aporte** | "Para atingir R$5.000 até dezembro, deposite R$417/mês". |
| **Múltiplas metas ativas** | Sem limite de metas simultâneas. |
| **Cards resumo** | KPIs: Metas Ativas / Total Guardado / Falta Guardar / Progresso Médio. |

### Problema que resolve
> "Sempre falo que vou guardar dinheiro mas nunca sei quanto já juntei nem quanto falta."

### Como comunicar nas redes

**Reels/TikTok — Motivacional**
> "Eu e minha namorada montamos a meta de viagem pra Europa ✈️ [mostra a meta com 🏖️ emoji, progresso em 34%] Cada mês o Buddy lembra quanto a gente precisa depositar."

**Story — Antes e depois**
> Antes: print de anotação no bloco de notas "juntar pra viagem: ??? rs"
> Depois: print da meta com barra de progresso em 67% e badge 🔥

**Post de carrossel — Como criar uma meta**

## 4. Cartões de Crédito

### O que é
Gerenciamento completo de cartões de crédito: cadastro, controle de faturas mensais, rastreamento de parcelamentos e importação de faturas por PDF ou foto.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Visual realista de cartão** | Cada cartão aparece com design de card com número, nome, bandeira e cor personalizada. |
| **10 cores + 6 bandeiras** | Visa, Mastercard, Elo, Amex, Hipercard, Outro. Cores automáticas por banco (Nubank = roxo, Inter = laranja, etc.). |
| **Fatura por mês** | A cada mês, o app calcula automaticamente o total das despesas no cartão. |
| **Status de fatura** | Badges dinâmicos: "Fecha em 3 dias", "Vence amanhã", "Paga ✓", "Em aberto". |
| **Barra de limite** | Visual do uso do limite: verde (<80%), amarelo (80-99%), vermelho (100%+). |
| **Parcelamento inteligente** | Ao importar uma compra parcelada (ex: 3/12), o app propõe criar as parcelas futuras automaticamente. |
| **Importar fatura por PDF** | Sobe o PDF da fatura do banco → IA extrai todos os lançamentos. |
| **Importar por foto** | Tira foto da fatura ou nota fiscal → OCR + categorização automática. |
| **Estorno e cancelamento** | Ações distintas: Estorno (lança receita), Cancelar (remove o lançamento), Reativar. |
| **Pagar fatura com 1 clique** | Seleciona a conta de débito → o app debita o saldo e marca a fatura como paga. |

### Problema que resolve
> "Tenho 3 cartões e não sei o total real que estou devendo no mês."

### Como comunicar nas redes

**Reels/TikTok — WOW factor**
> "Sobe o PDF da fatura do Nubank → [barra de carregamento] → 47 transações categorizadas. Em 8 segundos."
> *[câmera lenta na tela]*

**Story — Dica**
> "Sabia que o Bud detecta automaticamente a cor e a bandeira do seu cartão pelo nome do banco? 🎨 Cadastra o Nubank e veja."

**Post feed — Educativo**
> "Como funciona o parcelamento no Bud Finance 💳"
> Explica que ao importar "5/12" o app pergunta se quer criar as próximas 7 parcelas → salva tudo em meses futuros automaticamente.

## 5. Carteira (Contas)

### O que é
Hub de todas as contas bancárias e carteiras do usuário (conta corrente, poupança, dinheiro em espécie, benefícios). Permite importar extratos de qualquer banco.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Múltiplos tipos de conta** | Débito/Corrente, Poupança, Dinheiro/Espécie, Vale Refeição, Vale Alimentação, Outro. |
| **Saldo em tempo real** | Atualizado automaticamente a cada lançamento. |
| **Importar extrato CSV** | Sobe o arquivo CSV exportado do internet banking → processamento local (sem servidor). |
| **Importar extrato OFX/QFX** | Formato padrão dos bancos brasileiros e internacionais. |
| **Importar PDF (IA)** | Backend processa o PDF com OCR e IA → lista de transações para revisar. |
| **Importar por foto** | Fotografa o extrato impresso ou a tela → IA interpreta. |
| **Tela de revisão** | Antes de salvar, mostra cada transação para confirmar tipo, categoria e valor. |
| **Detecção de duplicatas** | Avisa se a transação já existe (mesma data + valor) antes de importar. |
| **Historico de importações** | Log de cada importação: arquivo, data, quantidade de registros, período. |
| **Conciliação de saldo** | Botão para ajustar o saldo da conta ao saldo real bancário. |

## 7. Limites de Gastos

### O que é
Sistema de controle de orçamento por categoria. O usuário define quanto quer gastar em cada área (ex: R$800 em Alimentação) e o app alerta visualmente quando está se aproximando ou ultrapassando.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Limite por valor fixo** | "Não gastar mais que R$600/mês com Restaurante". |
| **Limite por % da renda** | "Alimentação não pode passar de 30% do salário" — recalcula automaticamente se a renda mudar. |
| **Barra de progresso colorida** | Verde (<80%), amarelo (80-99%), vermelho (100%+). |
| **Cards de resumo** | KPIs: Total de Limites / Gasto Atual / Disponível. |
| **Copiar do mês anterior** | Gera limites do mês novo baseado no que foi gasto no mês anterior (+10% de margem). |
| **Arredondamento inteligente** | Sugestões arredondadas para o R$10 mais próximo. |
| **Notificação push** | Alerta no celular quando um limite atinge 80% ou é estourado. |
| **Navegação por mês** | Define limites diferentes para cada mês (ex: dezembro tem limite de festa maior). |

### Problema que resolve
> "Sempre gasto mais do que devia em delivery. Quero um alerta quando estiver exagerando."

### Como comunicar nas redes

**Reels/TikTok — Situação**

## 8. Recorrentes

### O que é
Automatização de lançamentos fixos e periódicos. O usuário cadastra uma vez e o app lança automaticamente no dia certo, todos os meses.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Periodicidade** | Mensal, semanal ou diária. |
| **Dia do mês configurável** | Escolhe o dia exato (1-31). Para meses curtos, o app ajusta para o último dia. |
| **Todas as formas de pagamento** | PIX, Débito, Crédito, Dinheiro, Transferência, Débito Automático. |
| **50+ categorias disponíveis** | Classificação completa desde a criação. |
| **Ativação/Desativação** | Pausa uma recorrente sem excluir (ex: assinatura cancelada temporariamente). |
| **Badge de origem** | Lançamentos automáticos chegam com ícone "REC" no extrato. |
| **Processamento automático às 6h** | Cron diário processa todas as recorrentes do dia. |
| **Botão "Processar Hoje"** | Força o processamento imediato para testes ou adiantamentos. |
| **Notificação push do dia** | No dia 1 do mês, o Buddy notifica: "Este mês você tem R$2.340 em contas fixas programadas". |

## 9. Dívidas

### O que é

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **6 tipos de dívida** | Empréstimo Pessoal, Financiamento, Cartão Parcelado, Consórcio, Dívida Informal, Outro. |
| **Cálculo automático (Tabela Price)** | Informa valor, taxa de juros e prazo → o app calcula a parcela mensal. |
| **Importar por contrato** | Sobe o PDF ou foto do contrato → IA extrai taxa, prazo e valor automaticamente. |
| **CET e IOF** | Campos para Custo Efetivo Total anual e IOF — transparência total do custo. |
| **Rastreamento de parcelas** | Marque cada parcela como paga → app atualiza saldo devedor automaticamente. |
| **Juros já pagos** | Mostra quanto do que você pagou foi para juros (e não abateu o principal). |
| **Barra de progresso de quitação** | Visual de quanto da dívida já foi pago. |
| **Alertas de vencimento** | Notificação push um dia antes do vencimento da parcela. |
| **KPIs gerais** | Dívidas Ativas / Saldo Devedor Total / Total Pago / Total em Juros. |
| **Integração com Insights** | Comprometimento de renda com dívidas aparece no score de saúde financeira. |

## 11. Mercado (Compras)

Gestão completa de compras no supermercado: cria listas antes de ir às compras, registra compras realizadas, compara preços históricos e importa cupom fiscal por foto.

### Funcionalidades detalhadas

| Funcionalidade | Como funciona |
|---|---|
| **Criar listas de compras** | Nome da lista + mercado + itens com nome, marca, categoria, quantidade e preço estimado. |
| **Modo Compras (in-store)** | Interface otimizada para o celular dentro do mercado: check os itens conforme coloca no carrinho, preenche preço e marca na hora. |
| **Histórico de preços** | Ao adicionar um item que já foi comprado antes, mostra o preço histórico para comparação. |

| **Importar cupom fiscal por foto** | Tira foto do cupom → IA lê e extrai todos os itens, preços e total. |
| **Importar cupom por texto** | Cola o texto do cupom eletrônico → IA interpreta. |
| **Resumo mensal** | Total gasto / Quantidade de compras / Ticket médio / Maior compra do mês. |
| **Breakdown por forma de pagamento** | Quanto foi no débito, crédito, dinheiro, PIX. |
| **Integração automática** | Cada compra registrada vira automaticamente uma despesa na categoria "Mercado". |
