# Instruções para Claude Code

Antes de trabalhar, leia [AI_WORKFLOW.md](AI_WORKFLOW.md) e [AI_HANDOFF.md](AI_HANDOFF.md), além dos documentos do projeto indicados pelo protocolo.

`AI_WORKFLOW.md` é a fonte comum de processo para Claude, Codex e qualquer outra IA que acesse este repositório. O histórico de chats e a memória privada de uma ferramenta não são compartilhados; registre avanços, decisões e o ponto de parada nos documentos versionados. Siga o protocolo de branch, proteção de alterações existentes, validação, autorização e atualização do handoff.
